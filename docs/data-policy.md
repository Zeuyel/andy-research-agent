# 数据与来源政策

## 上传范围
仅上传用户授权的私有整理成果：Agent/Skill、方法模块、整理后知识卡、必要短引文、来源 ID 与阶段进度。不上传原始全文、完整字幕、评论语料、附件、媒体、浏览器档案、凭据、日志或签名下载链接。

知识卡不是来源全文备份。讲者和转载作者必须区分；口述转写可能有误；检索命中不证明论点正确。原文上下文需在有合法访问权限的环境中回查。

## 权利边界
本项目不是 Andy 本人或其官方产品。来源内容的权利归原权利人；私有仓库不等于取得再分发许可。未经相应授权，不得将仓库改为公开、发布数据集或批量再分发知识卡。本仓库暂不添加开源 LICENSE，避免对第三方资料作不当授权。

## 排除与保留
- 7 个裸视频继续 hold，未纳入导出。
- 源工作区原始语料与凭据均保留原处，未移动或删除。
- 词法检索不是向量语义检索，也不自动核实科学结论。
- 源工作区的全文精确引文校验不能在本仓库独立复现，因为原始全文按用户选择不上传。
- 不包含采集、ASR、OCR或外部账号授权能力。
