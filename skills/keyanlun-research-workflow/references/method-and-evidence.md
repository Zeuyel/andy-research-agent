# 提炼方法与证据等级

> 本文件是根据「科研论」可访问的专栏目录、精华主题标题、置顶说明和页面中可见的研究流程内容，整理出的二次方法摘要；它不是原帖全文归档。使用时仍应回到原始论文或原始帖子核查具体主张。

## 一页任务卡

```text
任务：
研究对象/现象：
要回答的具体问题：
当前阶段：
已有材料：
缺口与约束：
本轮最小交付物：
完成判据：
```

## 检索词扩展表

| 维度 | 需要记录的内容 |
|---|---|
| 对象 | 材料、系统、样本、疾病/场景、上下位词 |
| 机制 | 现象、过程、因果候选、同义表达 |
| 方法 | 实验、表征、统计、计算、评价指标 |
| 限制 | 尺度、温度、时间、浓度、设备、样本量 |
| 来源 | 论文类型、数据库、作者/课题组、引用网络 |

## 证据卡模板

```text
主张：
来源：
原文位置：
证据类型：数据 / 方法 / 定义 / 综述判断 / 反例
适用条件：
支持或反驳：
可以放入：背景 / 方法 / 结果 / 讨论 / 局限
核查状态：未读 / 已看摘要 / 已核全文 / 待复核
我的解释（与原文分开）：
```

## 选题与提纲验收

- 题目是否同时满足对象、变量/机制和边界条件？
- 题目是否大到无法在现有资源内完成？
- 每个二级标题是否对应一个明确问题？
- 是否有一组 A 级证据支撑每个核心章节？
- 是否清楚区分事实、解释、推测和待验证假设？
- 是否包含失败条件、反例、局限或争议？
- 是否能从提纲反推出下一步检索和实验动作？

## 向导师/同行求反馈的格式

```text
背景（最多三句）：
我当前的判断：
我尝试过的路径：
具体卡点：
候选方案 A/B：
希望你帮我决定或检查的事项：
附：任务卡、关键证据卡、当前提纲
```

## 质量红线

1. 不把搜索摘要、二手转述或模型生成内容当作已核实事实。
2. 不为了填满参考文献而引用与主张无直接关系的论文。
3. 不把“相关”写成“因果”，不把单一案例写成普遍规律。
4. 不复制受限内容；保存必要的短摘录、出处和自己的结构化笔记即可。
5. 不把影响因子、期刊名或引用数直接当作证据质量。
