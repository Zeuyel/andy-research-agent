# 整理版知识检索

运行环境：Python 3.10+，仅标准库，离线运行，无需API Key。

从仓库根目录运行：

```bash
python3 skills/andy-research-agent/scripts/retrieve_knowledge.py "科研目标与最小验证" --limit 3
```

可选参数：`--root` 指定知识目录，`--limit` 限制结果。`--include-partial-comments` 为源版本兼容选项，但本仓库没有上传评论数据，开启也不会取得评论。缺失来源会通过 `missing_sources` 显示，读取错误通过 `source_errors` 显示。

本版包含43张主题阅读卡、27张本地文章卡、97张字幕知识卡和18条方法规则；保留适用条件、限制与必要短引。它不是全文、向量或联网搜索引擎。输出中的原卡只是已筛选的整理卡，不包含完整正文。词法相关性不代表证据支持度。

`retrieve.py` 为同一检索器的兼容入口。旧 `--id` / `--full` 不支持，任何文档都不能据此声称能够独立回查原始全文。若需逐字核对，必须使用另行合法持有的原始材料，不得为补齐依赖递归上传私人资料。
