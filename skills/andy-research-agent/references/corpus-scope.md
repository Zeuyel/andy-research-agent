# 语料范围与完成度边界

## 当前入口与计数原则

本版以仓库根目录 `export-manifest.json` 与 `docs/progress.md` 为准；以下数字描述源工作区，不表示相应全文随仓库上传。旧 `completion.json`、`organized/`、旧分析稿和交付版本是历史快照，不代表后续完成状态。必须分开计数：资源出现次数、独立主题、文字版本、取得正文、机器清洗、实际阅读、逐字引用核对、音视频校验、外部事实验证及真实用户效果。

## 仍然未完成

1. 绝大多数主题的逐条语义阅读、问答/转述归属复核。最新已读并集见检索叠加报告，不能以索引覆盖率代替阅读覆盖率。
2. 缓存之外的主题详情、评论分页，以及部分已取评论的上下文深读。
3. 581个平台图片、102个文件与各类外链的正文/图片核查；出现次数不是独立内容数，更不是已读数。
4. 字幕备选听写的语义对照与必要的音频裁定，以及无法确认的文字替代对应关系。
5. 远端文章版本差异、需现有授权浏览器渲染的文章和未获内容；失败、跳转和未访问不得互相混记。
6. 真实科研用户效果验证。程序回归、来源字符串匹配、作者自拟案例与非盲局部审阅均不是效果试验。

## Agent使用边界

- 优先检索已阅读卡；按 `knowledge-retrieval.md` 回读具体来源。命中与排名不代表事实已证实。
- 区分提问者、Andy、第三方讲者、总结者和AI反例；未明归属不默认Andy。
- 资料冲突与听写噪声保留，不把推断改写成直接引文，不把同源卡片数当独立证据数。
- 旧稿关于写作顺序、机械机制链、先导试验等归因或绝对化表述已修正，参看证据策略和回归记录。
- 原始正文含其他用户问答与授权内容，保持私有；未声称完全匿名，不打包成公开分享资料。
- 持续补采只用已有授权只读CLI或正常浏览器；没有jshook/CTF前置条件，不绕过权限，不新建凭证。
