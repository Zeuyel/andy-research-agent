# 证据与表达规则

## 来源层级

### S1：Andy 方法的直接来源

明确归属于 Andy 的主题段落和问答回答。必须分开 requester 问题、Andy 回答、第三方案例、AI 输出及评论。主题作者/owner 是 Andy 不代表全文每句话都属于 Andy；以“别人写的总结”“AI 示例”等形式引入的内容不自动变为 Andy 观点。仍需保留 topic_id 和原文短引定位。

字幕是说话内容的带噪记录，须核对讲者；第三方文字总结是二手来源，不能自动归为 S1。不能以摘要卡替代未读的完整原始材料来声称全文吸收。

### S2：结构化交叉归纳

多个主题、不同时间批次重复出现，且已抽象为可执行步骤。可以标为“已采用方法”，但仍不是科学事实或普适定律。

### S3：外部事实证据

论文全文、原始数据、代码、实验记录、正式政策和机构规则。涉及具体学科、统计、伦理、安全、版权和投稿政策时必须优先使用 S3。

### S4：候选线索

未阅读的单个主题、用户评论、视频简介、搜索摘要、AI 生成的引用或尚未核验的附件。只能产生待办，不能单独支撑确定性判断。单个主题经局部原文核对后可以支持有范围的窄主张，不因此自动成为交叉印证。

## 回答标签

在需要时使用以下标签：

- **Andy 方法**：来源于 S1/S2 的工作方式；
- **当前任务推理**：结合用户约束做出的分析；
- **待核验**：需要回到原文、数据、实验或正式规则；
- **个人化建议**：基于用户目标的方案，不应归因给 Andy。

```text
直接支持：
不能支持：

核查状态：候选 / 已核查 / 有冲突 / 已弃用
```

## 冲突规则

不同来源不一致时，不静默合并。比较任务目标、样本、时间、证据类型和失败成本；保留适用条件。如果仍无法裁决，明确写“有冲突/待复核”。

## 视频规则

当前 26 个长视频分段中，19 个已有字幕/转写/文字材料，7 个裸视频暂缓。文字总结只有在足以复述核心观点、步骤或论证时才算替代；视频简介、观看反馈和一句弱笔记不算完整替代。不得声称已学习裸视频。

“文字替代已定位”不等于“已取得全文并吸收”。以本地 `final/video-text/` 的逐项登记为准。多个字幕对应同一场讲座或同一文件是别名/分段关系，不重复当独立证据。
