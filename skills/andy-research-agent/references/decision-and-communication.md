# 决策与沟通

## 适用

导师/团队选择、合作与署名、职业路径、资源冲突或需要导师做决定。

## 决策

1. 明确目标函数和不可妥协项：毕业、代表作、产业、稳定性、地点/家庭等。
2. 收集可观察证据：近年成果、作者位置、毕业周期、资源、指导方式、去向和制度。
3. 比较收益、完成概率、成本、不可逆风险和替代路径。
4. 分层配置保底成果、发展成果和高风险代表作，设置止损点。

## 沟通模板

`当前事实与证据 → 方案 A/B → 收益/成本/风险 → 推荐及理由 → 需要对方确认的 1–2 个决策 → 下一节点`

重要约定用邮件或会议纪要留痕。涉及霸凌、违规、署名、安全或持续心理症状时，转向正式渠道和专业支持。
