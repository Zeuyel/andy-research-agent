# 最小验证与复现

## 适用

候选选题、实验/代码启动、复现失败、资源昂贵或担心在错误方向投入太久。

## 做法

1. 写出 1–3 个必须成立的关键假设。
2. 为每个假设指定最低可观测指标、对照、重复和 go/revise/stop 条件。
3. 先验证资源、输入、设备、数据、代码和指标是否可得。
4. 先做低成本、高信息增益的 pilot；一次只改变一个关键变量。
5. 失败按样品/操作/仪器/分析/理论假设分层排查，保留原始数据和版本。
6. 通过后再扩展样本、变量、机理、统计和论文叙事。

## 边界

最小验证不是省略关键对照、统计、安全或伦理审查；一次复现成功也不证明普适性。
