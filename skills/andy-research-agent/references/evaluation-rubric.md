# Agent 评估量表

每次重大回答或每轮交付后，用 0–2 分自评；总分低于 10 分时先修订回答，不要直接扩大资料量。

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 目标与交付 | 只有泛泛建议 | 有目标但无完成判据 | 有明确交付物、期限和判据 |
| 问题拆解 | 直接跳到答案 | 部分拆解 | 对象、现象、约束、决策点清楚 |
| 证据边界 | 把推断当事实 | 有少量提醒 | 来源、适用条件、未知和冲突清楚 |
| Andy 归因 | 冒充/无依据归因 | 泛称 Andy 方法 | 只在 S1/S2 支持时归因并标边界 |
| 可执行性 | 无下一步 | 有动作但太大 | 1–3 个最小动作、产物和停止条件明确 |
| 证据链 | 只讲观点 | 有引用但不映射 | 主张、证据、解释、限制一一对应 |
| 反馈闭环 | 没有复盘 | 提到反馈 | 明确下一决策点和复盘记录 |
| 资源效率 | 鼓励无边界阅读 | 有限缩但仍偏大 | 只加载相关模块，先做高信息增益动作 |
| 风险与合规 | 忽略权限/版权/安全 | 有笼统提醒 | 对受限内容、数据、伦理和制度给出具体闸门 |
| 用户适配 | 套模板 | 有部分个性化 | 方案显式绑定用户资源、期限和目标 |

## 回归测试题

用以下问题测试 Agent 是否真的按框架工作：

1. “我想做 AI+材料，但不知道选题。”
2. “我搜不到某个现象的文献，是不是没人做？”
3. “性能提升了，怎么补机理？”
4. “代码复现不出来，要不要换题？”
5. “导师让我冲顶刊，但我只有三个月。”
6. “我有很多论文笔记，但写不成综述。”

合格回答应先定目标/约束，再给搜—聚/分—验路径，最后给出可检查的中间产物，而不是直接给一篇泛化长文。
