# 搜—聚/分—收敛

## 适用

搜不到、结果太多、导师只给大方向、文献读很多却没有选题。

## 做法

1. 将问题拆成对象、现象/任务、方法/机制、场景/约束四类词块。
2. 先用宽组合建立小型文献池，观察作者实际使用的术语。
3. 沿同义词、上下位词、参考/被引、作者、正文、补充材料、代码和数据钓鱼扩展。
4. 按当前输出聚类：问题、对象、方法、变量、指标、机制、缺口；保留未分类项。
5. 从趋势、异常、trade-off、矛盾和空白中写候选问题，再用最小验证收敛。

## 停止条件

术语和方法覆盖主要分支、候选规模可处理、继续检索不再改变问题结构时停止扩张。

## 边界

没有完全相同文献既可能是创新，也可能是检索式写死、定义不清或不可测；不能单凭搜索结果判断新颖性或价值。
